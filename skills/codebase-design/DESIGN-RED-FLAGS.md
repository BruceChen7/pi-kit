# 设计红旗

设计候选在合成前逐条过一遍。**一条红旗就是改形状或否掉这个形状的理由**，不是待办事项。

用 [`SKILL.md`](SKILL.md) 的词汇（**module**、**interface**、**seam**、**adapter**、**depth**、**leverage**、**locality**）。不要写成 "component"、"service"、"API"、"boundary"。

前提：下一个贡献者是一个只看得到自己打开过的文件、会抄最近一个例子、会走「能编译的最短路径」
的 agent。**偏好那种「从一个文件看是对的改动，对整个仓库也对」的设计。**

## 浅模块

浅模块暴露一个大 interface，却几乎不隐藏复杂度。按公共表面**背后**藏着的capability 与 policy
相对表面本身的大小来判 depth。

不要把深模块和深调用链搞混。深调用链把理解分散在各层；深模块把 capability 收在一个 interface 后面。

看这几个迹象：

- 完成一次操作需要调用方协调好几个方法。
- 公共选项暴露了内部阶段或实现选择。
- 学会这个 interface 并不能让调用方少学实现。

**改法**：把复杂度拉进被调用方，宁可实现本身变得不那么简单。

## 信息泄露

信息泄露让多个模块依赖同一个内部决定。一个表示、策略或协议细节出现在不止一个地方，改它就要
协调着改。

**公共 API 上再导出传输层或 wire 类型就是泄露。** 把外部数据在 interface 之后解析成领域类型。
存储 schema、框架对象、协议细节保持私有。

## 按执行顺序切分

按执行顺序切分是**按执行先后**组织模块，而不是按它们拥有什么知识。把 load、validate、
transform、save 各自切一层，常常让同一个表示和它的不变量跨好几个边界重复。

**按领域知识与所有权分组。** 在不同时间运行的方法，只要守护的是同一批决定，就可以属于同一个模块。

## 直通方法

直通方法把同样的参数以同样的形状转给另一个方法。它加了一层，却没藏住任何复杂度。

删掉它，或把职责移给能完成整个操作的那个模块。只有当一个转发边界带来了策略、适配或一个**不同的**
抽象时，才保留它。

## 所有权分裂

不止一个模块写同一份状态，或各自留了一份副本。改了其中一个写者的 agent 看不到其他写者，于是
它们的规则会分叉。

**每份状态只能有一个 owner。** 别的模块读它，或者请 owner 去改。

## 一件事两种做法

设计支持了不止一种方式做同一件事。agent 会照抄它先找到的那一种，于是每种做法都在持续获得调用方。

**只留一种。** 把调用方迁走，在同一次改动里删掉其余的。

## 可导入的内部

调用方能 import 一个模块的内部。agent 会走「能编译的最短路径」直接 import，于是这些内部就成了
interface 的一部分。

**让内部从模块外部不可达**，从外面 import 会编译失败。

## 手工同步的清单

两个或更多地方列着同一批条目，加一条就要改每一处。只看得到其中一份清单的 agent 只会改那一份。

**只留一份，其余的从它派生。** 派生不出来的，就让构建在清单不一致时失败。

## 把偏离当成信号

草图就是契约。实现期间偏离草图，是要**提出来**的信号，不是可以悄悄吸收的摩擦。

函数需要草图没预料到的参数时，先问：是草图错了、需求漏了，还是实现越界了？

## 架构错了的 tell

实现持续产生草图吸收不了的摩擦时，**把草图扔掉**。不要把修法焊到一个错的架构上。

信号是一个**模式**，不是单个实例。下面任一条反复出现就是 tell：

- 同一种形状的 workaround 在互不相关的代码里反复出现。
- 多个互不相关的边界情况都需要专门分支。
- 类型需要 escape hatch（`any`、cast、实际上总被赋值的可选字段）才能编译。
- 草图说状态不共享，实现里却出现「我们需要一把锁」的条件反射。
- 调用方必须知道这个抽象的**内部规则**才能用它。
- 实现阶段出现两个或以上**同形状**的偏离。

用判断力。几个边界情况不足以否定一个架构；有些问题本身就该是复杂的。**数据里的复杂度不是设计里
的复杂度。**

### 扔掉重来时

1. 对着已经建出来的东西重跑一遍理解流程（`/skill:how`）。
2. 把新约束当成「一开始就在」来重设计，而不是打补丁（`redesign-from-first-principles`）。
3. 先减后加（`subtract-before-you-add`）。**新草图在长大之前，应该比旧草图更小。**
4. 回到草图阶段，重跑候选探索。
