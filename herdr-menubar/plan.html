Herdr Agent 状态菜单栏

用 Glimpse 的 macOS 菜单栏模式(statusItem)展示 Herdr 中所有 agent 的运行状态与完成消息

✅ 可行

零改动 herdr 源码:通过 herdr 原生 Unix Socket JSON API 读取 + 订阅事件,配合 glimpseui 的 statusItem() 系统菜单栏模式(popover 内为集中式列表),纯 Node.js 即可实现;点击行可直接拉起对应 agent。核心链路已在本机实测通过。

1. 背景与目标

🎯 目标

  • 系统菜单栏图标:显示 working 汇总(如 ● 2),点击弹出集中式列表
  • popover 内按 workspace 列出所有 agent 及其状态(working / idle / blocked / done / unknown),含最后一条消息
  • 点击某一行拉起对应 agent(herdr 切到该 workspace 并聚焦该 agent 的 pane)
  • herdr 未运行时显示离线状态

🧩 技术栈

  • herdr v0.8.0 (Rust) — 已内置 JSON API 服务端
  • glimpseui v0.8.1 (pi-kit/node_modules) — WebView 微 UI,菜单栏 popover + 双向 JSON 通信
  • Node.js ≥18 — 胶水层:连 socket、维护状态、驱动 Glimpse
  • 无 Electron、无第三方依赖

2.2.1 UI 形态:系统菜单栏 + popover 集中式列表

采用 Glimpse 的 statusItem() 菜单栏模式:菜单栏图标常驻(零屏幕占用),点击弹出 NSPopover — popover 内是集中式列表 UI:按 workspace 分组,每行 = 状态 + 标题 + 完成后最后一条消息,可筛选/排序。收起后菜单栏图标保留汇总数字(如 ● 2);数据持续在 Node 内存中更新,每次展开都是最新状态。不采用常驻浮动窗口方案(用户明确要求系统菜单栏,不需要常驻显示)。

核心特性 ① — 展示完成后最后一条消息:agent 状态由 working 变为 idle/done(本轮完成)时,Node 侧调用 pane.read(source: recent, lines: N, format: text, strip_ansi: true)读取该 pane 最近输出,取最后一条完整消息存入 store,popover 行内以摘要形式展示;点击摘要可展开全文。读取仅发生在状态切换瞬间,不做高频轮询。

核心特性 ② — 点击行拉起 agent(已实测通过):点击某一行时,Node 发送 workspace.focus { workspace_id } 切到该 workspace,再发 agent.focus { target: pane_id }(target 用 pane id 而非 agent 名 — 同名 agent 不唯一时会报 NotFound);herdr 立即切到该 workspace 并聚焦对应 agent 的 pane。实测:焦点由 w4Z:p1 切到 w10:p4,两步请求均返回成功,且可恢复原焦点。

焦点在 popover 上也能拉起:focus 请求走 Unix socket,与用户当前焦点在哪个 app 无关 — 即使焦点停在本 popover 上,herdr 内部也会照常切换。唯一区别是 macOS 前台窗口:herdr 收到 focus 请求后不会自动把自己激活到前台(源码中 activate 仅用于通知),因此 Node 在发完请求后再补一步 osascript 将 herdr 进程置前,用户即可立即看到该 agent 的终端。

3. 架构设计

1

启动时 session.snapshot 拉全量单次请求连接,获取所有 pane 的 agent / agent_status / title / workspace_id

2

开启订阅连接 events.subscribe对每个有 agent 的 pane 订阅 pane.agent_status_changed;同时订阅 workspace.created/closed、pane.created/closed、pane.agent_detected 维护集合变化;此连接长驻,服务端推送事件

3

事件驱动更新 AgentStorestatus 变化 → 更新内存状态 → 聚合统计(working 数 / 总数 / 按 workspace 分组);状态由 working 变为 idle/done 时,调用 pane.read 读取最近输出并截取最后一条消息,存入该 agent 条目

4

增量渲染(双通道)图标: item.setTitle('● 2') 更新汇总;popover: win.send(js) 推送最新 viewData(含最后消息)重绘 — 收起时数据也持续更新,展开即最新

5

交互回传点击 agent 行 → window.glimpse.send({wsId, target: paneId}) → Node 发 workspace.focus + agent.focus 拉起该 agent;点击消息摘要 → popover 内展开全文

6

断线与重连socket 消失/连接错误 → 图标变灰 "herdr 离线";每 2s 探测 socket,恢复后重新 snapshot + 订阅

4.2 核心代码骨架

herdr-client.mjs — 连接与协议:

import net from 'node:net';
import { EventEmitter } from 'node:events';

export class HerdrClient extends EventEmitter {
  constructor(socketPath) { super(); this.socketPath = socketPath; }

  /** 单次请求:发一行 JSON,读一行响应(协议: newline-delimited JSON over unix socket) */
  request(id, method, params) {
    return new Promise((resolve, reject) => {
      const sock = net.createConnection(this.socketPath);
      let line = '';
      sock.on('connect', () => sock.write(
        JSON.stringify({ id, method, params }) + '\n'));
      sock.on('data', (c) => {
        line += c;
        if (line.includes('\n')) {
          const msg = JSON.parse(line.slice(0, line.indexOf('\n')));
          msg.error ? reject(new Error(msg.error.message)) : resolve(msg.result);
          sock.destroy();
        }
      });
      sock.on('error', reject);
      sock.setTimeout(3000, () => { reject(new Error('timeout')); sock.destroy(); });
    });
  }

  /** 订阅:独立长连接,服务端先回 subscription_started,之后持续推事件 */
  subscribe(subscriptions, onEvent) {
    const sock = net.createConnection(this.socketPath);
    let buf = '';
    sock.on('connect', () => sock.write(JSON.stringify(
      { id: 'sub', method: 'events.subscribe', params: { subscriptions } }) + '\n'));
    sock.on('data', (chunk) => {
      buf += chunk;
      let i; while ((i = buf.indexOf('\n')) >= 0) {
        const msg = JSON.parse(buf.slice(0, i)); buf = buf.slice(i + 1);
        if (msg.event) onEvent(msg);   // { event, data }
      }
    });
    sock.on('close', () => this.emit('sub-closed'));
    sock.on('error', () => this.emit('sub-closed'));
    return sock;
  }
}

agent-store.mjs — 纯函数状态机(可单测):

// statuses: idle | working | blocked | done | unknown
export function initFromSnapshot(snapshot) {
  const panes = new Map();
  for (const p of snapshot.panes) if (p.agent) panes.set(p.pane_id, toPane(p));
  return panes;
}
export function applyEvent(panes, ev) {
  const d = ev.data;
  switch (ev.event) {
    case 'pane.agent_status_changed':
      if (panes.has(d.pane_id))
        panes.set(d.pane_id, { ...panes.get(d.pane_id),
          status: d.agent_status, title: d.title ?? panes.get(d.pane_id).title });
      break;
    case 'pane.agent_detected':   /* 新 agent 进入 → 需要 pane.get 补详情 */
    case 'pane.closed': panes.delete(d.pane_id); break;
    /* workspace.created/closed → 维护 workspace 元信息 */
  }
  return panes;
}
export function viewData(panes, workspaces) {
  const byStatus = { working: 0, idle: 0, blocked: 0, done: 0, unknown: 0 };
  const rows = [...panes.values()].map(p => ({
    ...p, wsLabel: workspaces.get(p.workspace_id)?.label ?? p.workspace_id,
  })).sort((a, b) => (a.status === 'working') - (b.status === 'working') || a.wsLabel.localeCompare(b.wsLabel));
  rows.forEach(r => byStatus[r.status]++);
  return { byStatus, rows };
}

menubar.mjs — 入口:系统菜单栏 + popover 集中式列表:

import { statusItem } from 'glimpseui';      // 系统菜单栏 + popover
import { HerdrClient } from './herdr-client.mjs';
import { initFromSnapshot, applyEvent, viewData } from './agent-store.mjs';
import { renderPanelHtml } from './view.mjs';

const item = statusItem(renderPanelHtml(emptyView()), {
  title: '…', width: 380, height: 520,
});

// 图标 = working 汇总;popover = 集中式列表(含最后消息)
function paint() {
  const v = viewData(panes, workspaces);
  item.setTitle(v.byStatus.working > 0 ? `● ${v.byStatus.working}` : '○');
  item.send(`window.__render(${JSON.stringify(v)})`);   // 收起时也持续更新,展开即最新
}

async function onStatusChanged(ev) {
  const prev = panes.get(ev.data.pane_id)?.status;
  panes = applyEvent(panes, ev);
  // 本轮完成 → 读最后一条消息(仅在状态切换瞬间,不做高频轮询)
  if (prev === 'working' && ['idle', 'done'].includes(ev.data.agent_status)) {
    const pane = panes.get(ev.data.pane_id);
    pane.lastMessage = await readRecentText(client, pane.pane_id, 40);
  }
  paint();
}

// 点击 agent 行 → 拉起该 agent;点击摘要 → 展开全文
item.on('message', (m) => {
  if (m.wsId) client.request('w', 'workspace.focus', { workspace_id: m.wsId });
  if (m.target) {
    client.request('a', 'agent.focus', { target: m.target });  // target = pane_id(实测通过)
    activateHerdr();   // 焦点在本 popover 上也生效: 请求走 socket, 与前台无关
  }
  if (m.expand) item.send(`window.__expand(${JSON.stringify(m.expand)})`);
});

// macOS 前台激活 — herdr 收到 focus 不会自动置前窗口, 需补一步 osascript
import { execFile } from 'node:child_process';
function activateHerdr() {
  execFile('osascript', ['-e',
    'tell application "System Events" to set frontmost of first process whose name is "herdr" to true']);
}

herdr-client.mjs — 读取 pane 最近输出(完成后取最后消息):

// pane.read: source=recent, lines=N, format=text, strip_ansi → 最近 N 行纯文本
export async function readRecentText(client, paneId, lines = 40) {
  const r = await client.request('r', 'pane.read', {
    pane_id: paneId, source: 'recent', lines, format: 'text', strip_ansi: true,
  });
  return r.text;   // PaneReadResult { pane_id, text, revision, truncated, ... }
}
// 最后一条消息 = 按空行分段取最后一个完整段落,剔除状态行/滚动噪声

5. 风险与边界

风险影响对策
订阅连接断开(herdr 重启)状态停更连接 close/error → 重连并重新 snapshot + 订阅
named session(多实例)socket 不在默认路径扫描 sessions/*/herdr.sock,支持 HERDR_SOCKET_PATH 环境变量,可合并显示多实例
popover 为 transient收起后无交互收起时靠菜单栏图标汇总表达;数据持续在内存更新,展开即最新
agent 检测依赖 herdr manifest新 agent 可能识别为 unknownunknown 状态照常显示;herdr manifest 机制可持续更新
事件突发(滚动输出)频繁重绘状态变化事件天然低频(仅 status 切换);渲染 debounce 100ms
状态一致性订阅遗漏事件事件带 state_change_seq;定期(如 30s)静默重新 snapshot 对账,防止漂移
