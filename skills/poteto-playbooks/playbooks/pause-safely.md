# Pause safely

**你拥有一次干净的停机。留下一个冷启动 agent 能接着走的检查点。** 只在明确要停时做。听到「继续」「我睡了，别停」「不要停」时不停。

1. 停在安全边界。做完或退出当前原子步骤。不开新活，取消所有嵌套子代理。
2. 停机不碰不可逆动作。没有已开出的 PR 就不开，不推送。
3. 让工作可持久。把未提交改动作为一个清楚的 `wip:` 提交留在当前分支，别丢东西。树是坏的就在提交正文里一行说明。
4. 在上下文之外写 resume note。记下意图、正在做什么、进度与已验证部分、当前状态、下一步、关键文件、坑。因压缩触发时写进 `/tmp/<slug>-resume.md`。已有 `/skill:show-me-your-work` 决策轨时指过去，不要复制。

**回复：** 你在循环的哪一步，哪些在磁盘上哪些还在脑子里（给路径，不倒 diff），你做的提交与树是否干净，恢复时的第一个动作。这是停机，不是最终报告。
