# Sharpen

我要的是这件事更深，不是更大。改写成新任务之前，先答四件事：

1. 这个领域里一个真正专业的人在这里会做什么，是我没要求的。
2. 他会从什么原始材料开始，而不是从我手上这些已经消化过的东西。
3. 他具体会用哪些方法和工具。
4. 除了你和我，还有什么能证明结果是对的。

然后按这四条重写我的要求，只要求这个。

让重写后的任务要求 agent：凡是能用实验定夺的选择，先做原型，再按观察到的结果推荐一个选项；只有实验无法定夺的产品或偏好选择，才留给我决定。
